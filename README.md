I'm a computing enthusiast focused on the advanced side of Software Engineering: **architecture, cloud computing, DevOps and security**. I build **scalable and reliable back-end systems with Java and Go**, and I care about code that is clean, easy to read and secure.

- 💼 **Network Analyst** at **Brasil TecPar**
- 🎓 **Software Engineering** student at **PUC Minas**
- 🧩 Architecture: **microservices**, **event-driven architecture**, **event-driven microservices** and **hexagonal architecture**
- ⚙️ Delivery: **CI/CD**, **Infrastructure as Code**, automated pipelines with **GitHub Actions**
- 🧪 Quality: **Clean Code**, **SOLID**, unit, integration and **E2E tests** running before anything reaches `main`
- 📈 Scale: **horizontal vs. vertical scaling**, **load balancing**, and when each one is the right call
- 🤝 **Open to opportunities** in Back-End, Cloud and DevOps
